# LosCollector
Aplicação Python/Streamlit para coleta e gerenciamento de playlists M3U/M3U8, com biblioteca, deduplicação, organização e diagnóstico.

## Execução
Python 3.11+
pip install -r requirements.txt
streamlit run app.py

## Observação
O Studio prepara projetos de materiais promocionais, mas renderização de vídeo e integração com catálogos externos exigem APIs/serviços específicos e não são fingidas como implementadas.
O coletor não contorna autenticação, CAPTCHA, DRM, paywall ou controles de acesso.
